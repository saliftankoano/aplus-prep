# Domain

This glossary records project-specific language used across the product and codebase.

## Current source bank

A publisher- and version-labelled question collection targeting the active 220-1201 or 220-1202 exam series. The current banks are DumpsGate v17.5 for Core 1 and DumpsGate plus SurePass v5.3 for Core 2.

Public interfaces use short source aliases: **Dump** for the `dumpsgate` source slugs and **Sure** for the `surepass` source slug. The stable slugs and import metadata retain their original provenance so existing links and rebuilds remain compatible.

## Source-labelled deck

A bounded practice set whose publisher/version remains visible in the deck browser, quiz workspace, and results actions. Its quiz URL includes a `?source=` slug.

## Legacy collection

An original A+ Prep bank kept available for additional review and URL compatibility. It is not presented as a current third-party source bank.

## Exam cockpit

The shared visual and interaction language for the public site: calm ink/navy surfaces, compact readiness information, clear Core 1/Core 2 accents, and distraction-free quiz controls.

## PBQ

A performance-based question that tests a configured state or relationship through an interactive task rather than ordinary answer buttons. Planned types include matching, drag-and-drop, hotspots, dropdown configuration, and topology/configuration.

## Exact-set grading

The multi-select rule requiring the learner's selected answer indexes to match the full correct-answer set with no omissions or extras.
